Zephyr RTOS

I have 119 merged pull requests in zephyrproject-rtos/zephyr, spanning drivers, the test infrastructure, and C++ support.

  • C++ support

    Fixes for compiler warnings, C++ version detection, and C++ initialization of ADC channel configuration, plus support for mocked __atomic_compare_exchange_* builtins.

  • Testing and tooling

    gtest 1.15.0 support, a fix for the gTest harness in Twister, better gcov symlink handling, and clearer ztest skip logging.

  • Drivers and RTIO

    A default I2C submit handler for RTIO, an NPCX I2C controller driver, I2C shell fixes, and ESP32 ADC fixes.

  • Build system

    Custom sysroot support for native_sim builds.

Pigweed

Pigweed is Google's collection of embedded libraries and tooling. I work on its Zephyr integration and am listed as an owner of the pw_log_zephyr, pw_chrono_zephyr, and pw_sync_zephyr modules.

  • zephyr-pigweed

    A public tutorial that shows how to use Pigweed's C++ libraries inside a Zephyr project: West manifest setup, pw::StringBuffer, PW_LOG_INFO(), pw::containers::FlatMap, and gTest unit tests run through Twister on QEMU.
